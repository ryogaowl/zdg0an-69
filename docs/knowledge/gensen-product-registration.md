## 公開前の検索非表示

`seo.hidden` はテーマ設定ではなく、ストアの商品に付くメタフィールド。テーマの下書きだけでは隔離されない。

1. 商品のメタフィールド定義に `seo.hidden` が既にあるか確認する。既存定義・既存値がある場合は再作成せず利用する。
2. 未定義なら namespace `seo`、key `hidden`、タイプ「整数」`number_integer`、単一値として定義する。公式手順に合わせて最大値は1にする。
3. 対象商品の値を `1` に設定し、保存後に定義・型・値を再取得して確認する。
4. 商品は下書き・販売チャネル未公開を維持する。検索非表示の値だけを理由に商品を公開しない。
5. 管理画面の商品プレビュー／テーマエディターで商品と `gensen` テンプレートを指定し、実際に発行された確認URLを共有する。オンラインストアでの表示に商品公開が必要な場合は、その商品・チャネル・操作を明示して承認を得る。

`seo.hidden = 1` は検索エンジン、サイトマップ、ストア内検索、Shopify Catalog から商品を隠す設定。コレクションや関連商品の表示、直接URLへのアクセスを全面的に制限するものではない。公開前のアクセス制限は下書き・チャネル未公開と分けて管理する。[Shopify公式の非表示手順](https://help.shopify.com/en/manual/promoting-marketing/seo/hide-a-page-from-search-engines)

## 画像・説明文とテーマ設定

- 商品メディアには正式なボトル画像、ラベル、ケース画像等を登録する。未登録時はFigma原本のボトル画像を仮表示する。サムネイルは登録されたメディア数に追従する。
- ブランド名、商品補足名、ケース表記、バッジ、ストーリー本文と画像、FAQ、関連商品、ナビゲーション先はテーマエディターで編集する。
- FigmaのFAQは仮文言。回答も「回答文は準備中です。」とした。公開前に確定する。
- 「糖質3.5%・200kcal・タンパク質22g」はユーザー確認済みの仮文言。編集・非表示にできる。販売用の商品情報としては未確定。
- ストーリーの成分値・水質・身体への作用等の文言はFigmaを転記したもの。商品情報の承認者による最終確認を受けてから公開する。
- DAICHIは関連商品カードの仮表示のみ。商品登録は今回の対象に含めない。正式商品を登録した後でテーマの「関連商品」に指定すると実際の商品名・価格・画像・URLを表示する。
- 初期状態は「カート追加を有効にする」オフ、「価格・数量・バリエーションを表示」オフ。価格・在庫・配送・購入方法が確定してからオンにする。
- 定期購入は仮枠のまま。Mikawaya導入後に仮枠をオフにし、アプリブロックを配置して購入プランの送信・カート・継続条件表示を実ストアで検証する。現時点では定期購入専用バリエーションの購入を無効化しているため、アプリ設置だけで連携完了とはならない。
- Figmaの画像原本を保持しているため、大きい写真は容量が大きい。正式画像は各ストーリーブロックの画像設定にアップロードして指定するとShopify CDNのレスポンシブ画像を利用できる。現状の原本フォールバックにも遅延読込を設定した。

## 権限取得後の作業順

1. 対象ストアを読み取りで再確認し、既存商品・SKU・メタフィールド定義との重複を確認する。
2. 実値が揃った登録内容を確定し、対象商品への書込み承認範囲を確認する。
3. 下書き商品と必要な商品データを作成し、`seo.hidden=1` を設定して再取得確認する。
4. `gensen` テンプレートを割り当てる。未公開テーマだけにあるテンプレートが商品管理画面に現れない場合は、権限のあるAPIでsuffixを指定するか、テーマエディターで対象商品を選んで確認する。本番テーマへ仮ファイルを勝手に追加しない。
5. 正式な商品プレビューを発行し、PC/SP、実商品画像・価格・在庫・カートを確認する。
6. Mikawayaの契約仕様とアプリ連携を確定し、購入プランと通常購入を検証する。
7. 仮文言、未設定リンク、画像容量を確認し、公開の明示承認後に販売状態と公開テーマを切り替える。検索公開する場合は `seo.hidden` を解除して再確認する。

商品データの基本項目は [Shopifyの商品詳細仕様](https://help.shopify.com/en/manual/products/details/product-details-page) を参照。商品データの更新・復旧は、テーマのGit操作とは別作業として扱う。
